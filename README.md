# 🍽️ Fusion Gourmet
 
**Where culinary traditions collide and flavors transcend borders.**
 
Fusion Gourmet is a fine-dining restaurant website that showcases our philosophy of blending Eastern and Western gastronomy into a singular, unforgettable experience.
 
## Features
 
- Curated seasonal menu with interactive dish previews
- Online reservation system
- Chef's story & philosophy
- Private dining & events booking
- Wine pairing guide
## Tech Stack
 
HTML5 · CSS3
